# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do not open public issues for security problems.
Report them privately via [GitHub Security Advisories](https://github.com/tum-zulip/go-campusbot/security/advisories/new).

We aim to acknowledge reports within 7 days and to publish a fix or mitigation as soon as possible after triage.
